## What I'm Building

**[Dokai V2](https://github.com/TestingGuyz/Dokai_V2)**
Medical AI — bill auditing, lab analysis, symptom check. Two-pass pipeline: MedGemma for vision + LLaMA for reasoning. Runs on desktop, Android, Colab.

**StudyMate AI** *(in progress — HACKHAZARDS '26)*
Adaptive study assistant for Classes 6–12. Neo4j tracks learning state per student. Spaced repetition, mock exams, AI grading of handwritten answer sheets.

**[Moi](https://github.com/TestingGuyz/Moi_Developing)**
Real-time object detection with descriptions. DINOv3 bounding boxes + Gemini Live narration. Basically giving an AI the ability to see and talk about what it sees.

**HANUMAN**
Voice assistant on Raspberry Pi Zero 2W. Wake word, STT/TTS with ElevenLabs, web search. My take on a personal Alexa.

**[Military Vision Car](https://github.com/TestingGuyz/MPBlitz-25_Spy_Military_Car_Final)**
ESP32-CAM mounted car with 20+ Roboflow-trained models (90%+ accuracy), two-stage verification (NMS + Gemini AI), GPS tagging, mobile web control.
