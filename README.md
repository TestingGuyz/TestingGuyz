## 🚀 What I'm Building

**[Dokai V2](https://github.com/TestingGuyz/Dokai_V2)** — Medical AI
Bill auditing, lab report analysis, symptom check. Two-pass pipeline: MedGemma for vision + LLaMA for reasoning. Runs on desktop, Android, and Colab.

**[StudyMate AI](https://github.com/EgoisticCoder/StudyMate_Hackazrds-26.git)** — Live edtech platform 
Adaptive study assistant for Classes 6–12. Neo4j behavioral graph tracks per-student learning state; RAG pipelines, spaced repetition, mock exams, AI grading of handwritten answer sheets. Built on Sarvam Bulbul V3 (TTS/STT), Groq Llama-3, Expo React Native. Selected for the **Sarvam Startup Program**.

**RAKSHA** — Disaster-response agentic platform
Five-layer offline degradation stack, BLE mesh networking, Neo4j live zone mapping, Twilio SMS fallback, and four autonomous agents. Started as a HACKHAZARDS '26 build; now on a 12-month roadmap (BullMQ + Redis, Render deployment, Sarvam voice SOS, TypeScript/Vite admin dashboard).

**ARIA Rover** — Disaster-response rover
Radxa Cubie A7Z + Arduino UNO Q. Nine-model AI inference pipeline with a custom dataset for traversability estimation. Built for the Robu.in × Arduino Contest.

**[Moi](https://github.com/TestingGuyz/Moi_Developing)** — Real-time visual narration
DINOv3 bounding-box detection + Gemini Live narration — an AI that sees and talks about what it sees.

**HANUMAN** — Voice assistant on Raspberry Pi Zero 2W
Wake word detection, ElevenLabs STT/TTS, live web search. A from-scratch take on a personal Alexa.

**[Military Vision Car](https://github.com/TestingGuyz/MPBlitz-25_Spy_Military_Car_Final)** — ESP32-CAM surveillance car
20+ Roboflow-trained models (90%+ accuracy), two-stage verification (NMS + Gemini AI), GPS tagging, mobile web control.

**[NeoPet](https://github.com/EgoisticCoder/NeoPet-Virtual-Pet-Web-App.git)** — AI-powered virtual pet
Built in ~1.5 hours for X Celsior '26. AI chat companion, TTS voice, XP/leveling economy, and 3 mini-games. 🥇 1st place, X-Hack.
